
## 启动可视化页面

```bash
aem enter
aem bootstrap start --plus


aem bootstrap stop
aem bootstrap restart
```

## 数据包下载

浏览器点击下载，并在容器终端运行指令`watch -n 1 ls -lh /apollo/data/map_data/`查看下载进度。

## 同步配置文件

```bash
将`/opt`中的二进制文件提取出配置文件保存到`/apollo_workspace`与本地项目路径中。
buildtool profile config init --package planning --profile=default
aem profile use default
```

## 定速巡航实验

修改`profiles/default/modules/planning/planning_component/conf/planning.conf`设定定速巡航速度
```conf
# --default_cruise_speed=11.8
--default_cruise_speed=2
```

实验场景设置
```
模式：PnC
操作：Sim_Control
环境资源：
    高精地图： Sunnyvale Big Loop
车辆：Mkz example
```
