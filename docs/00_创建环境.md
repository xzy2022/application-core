
## 删除容器
```bash
# 先进入工程目录
cd application-core
# 删除容器
aem remove
```

## 克隆项目并启动容器

```bash
git clone https://github.com/ApolloAuto/application-core.git application-core
cd application-core
bash setup.sh
aem start
```

执行`buildtool build -p core`编译后文件变化情况如下
```bash
# 容器
[xzy@in-dev-docker:/apollo_workspace]$ ls /apollo
# 原有目录: data log modules output
# 新增目录: cyber scripts
data  log  modules  output  cyber  scripts

[xzy@in-dev-docker:/apollo_workspace]$ ls /apollo_workspace/
# 原有文件: LICENSE README... core docs log profiles WORKSPACE data kill_all.sh output setup.sh
# 新增/生成: CPPLINT.cfg dev third_party tools 以及 bazel-* 软链接
LICENSE    README_cn.md  core  docs         log     profiles
README.md  WORKSPACE     data  kill_all.sh  output  setup.sh
CPPLINT.cfg  dev  third_party  tools  bazel-apollo_workspace  bazel-bin  bazel-out  bazel-testlogs

# 本地项目
# 新增 WORKSPACE
```
可以确定容器内的`/apollo_workspace`目录和本地项目目录是同一个目录
